
# 💳 Credit Scoring Model

## 📌 Project Overview
This project uses Machine Learning algorithms to predict customer creditworthiness based on financial information.

## 🎯 Objective
To build a classification model that helps identify whether a customer is creditworthy.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Algorithms
- Logistic Regression
- Decision Tree
- Random Forest

## 📊 Evaluation Metrics
- Precision
- Recall
- F1-Score
- ROC-AUC

## 📁 Project File
- Credit Score .ipynb – Complete project implementation.
